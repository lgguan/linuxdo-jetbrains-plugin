# 楼层导航与回复刷新

底部导航栏统一提供刷新回复（F5）、当前楼层、滑块及楼层号输入；窄窗口下滑块独占一行，正文为导航栏预留空间。状态及冷却提示显示在同一栏。

- 相邻分页从已加载内容的最小 / 最大索引向外取最多 20 条，不因跳到尾部而补抓中间数千层。
- 程序定位不会触发自动预取；初始页面及用户继续滚动最多触发一批，响应返回本身不会启动下一批。
- 拖动滑块仅预览，松开后定位；连续远程跳转至少间隔 800ms，等待期间只保留最后一个目标。已加载楼层直接本地定位。
- 论坛读取收到 HTTP 429 后，所有话题共用服务器 Retry-After 冷却。正文停止远程跳转、刷新和分页，保留已加载内容及本地定位；冷却结束等待手动重试。
- 如跳转跨过尚未加载的区间，可用楼层号或滑块直接定位中间目标；不会后台补齐整个区间。

浏览器回归及截图生成入口见[工具说明](../tools/README.md)，发布前检查见[发布检查清单](release-checklist.md)。
