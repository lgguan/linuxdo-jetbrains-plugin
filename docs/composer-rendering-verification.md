## 实现范围

- 阅读器和编辑器预览共用安全 HTML 处理：保留引用、链接卡片、表格、图片、标题锚点、折叠和隐藏内容；标题及图片标识按帖子隔离。跨话题引用定位对应话题和楼层。脚本、事件属性及嵌入框架被过滤，代码中的 BBCode 不执行。
- 本地 Markdown 使用 CommonMark 及表格、自动链接、删除线、任务列表扩展，兼容普通 Discourse 引用、折叠和隐藏语法；正常换行得到保留。公式、Mermaid、投票等提供回退内容或网页入口。
- 发帖和回复使用同一套扁平图标工具栏，按格式、插入、历史及预览分组；标题、有序列表、任务、折叠和隐藏放在“更多”菜单。图标随 IDE 主题与缩放调整，提供提示、辅助功能名称及原有格式快捷键。格式替换作为一次撤销操作。
- 编辑框统一边框、内边距、字号和底部字数显示。预览默认收起，关闭时不启动本地渲染或初始化预览浏览器；打开后随输入更新，保留预览滚动位置。眼睛图标切换显示，旁边菜单选择本地或论坛引擎预览。窄窗口下工具栏换行，预览移到正文下方。
- 论坛引擎预览使用临时只读浏览器加载原生前端渲染引擎，禁止非 GET/HEAD/OPTIONS 请求；完成或超时后释放。预览不发送帖子或保存草稿。
- 图片上传按触发时的光标位置插入，排队上传；未完成或失败任务阻止发送，失败可重试或明确舍弃。发布期间禁止正文变更，HTTP 5xx、408、响应无法解析或发布结果不明时保留正文和草稿并阻止直接重发；审核队列结果独立处理。
- 新话题直接进入编辑器，自动恢复服务器原生单份 `new_topic` 草稿的标题、正文、版块及标签；同一账号共用一个活动编辑器。使用共享的串行草稿会话，保留未知字段，冲突完整对照，清理前后核对服务器状态。普通回复保留 `topic_<ID>` 键及回复目标兼容性。此次入口、尺寸和选择器优化的验证记录见 [编辑器选择验证](composer-selection-verification.md)。
- 当前发布表单从论坛获取版块权限、字数及标签限制，按版块查询标签及禁用原因；失效版块、禁用标签和会话切换阻止提交。不支持的特殊草稿保留并提供网页入口。正文与标题不新增本机持久化。
- 区分两类 429：错误内容带 Cloudflare 字样、`cf-mitigated: challenge` 或验证页面标记时提示完成人机验证；普通 429 提示论坛请求频率限制。列表、编辑器和 Java/JCEF 的底层分类一致；草稿窗口保留正文并显示“验证后重试”。仅代理服务器标头出现 Cloudflare 不视为验证页面。通知冷却提示说明暂停的操作和剩余时间。

17:56 冷却后的单次复测在首次读取确认 Cloudflare 验证标记（HTTP 429），报告 `build/draft-handoff/d1d872a5-292e-4850-9a34-3063aeea1ea7/blocked-response.json`：`verificationRequired=true`、`operation=GET`、`postSubmitted=false`。未进入写入，进程已退出；验证门禁阻止冷却到期后的自动重试。用户随后确认已验收，本次不再自动复测；不据此认定人机验证已解除。

`tools/draft-handoff.py` 将原生网页写请求限制为该话题、普通回复动作及指定正文的草稿保存，拒绝帖子提交、其他草稿及其他写入。真实联调的 API 请求从完成后计算至少 5 秒间隔，CSRF 与写入之间也间隔 5 秒；原生网页 API 同样限速。收到 429 后停止全部后续请求，包括收尾读取；跨运行冷却文件位于 `build/draft-handoff/rate-limit.json`，等待不少于 30 分钟或更长的 `Retry-After`。可用 `--wait-cooldown` 仅在本地等待后尝试一次，期间不请求论坛；等待原生网页编辑器的桥接响应最多 90 秒。

联调脚本在浏览器内检查错误内容，只返回状态、验证标记和 `Retry-After`，不导出完整错误页或凭据。确认需要 Cloudflare 人机验证时，冷却记录增加 `verificationRequired`，此后即使时间到期或指定等待模式，也停止自动尝试，直到用户完成验证。
