# 首次打开帖子的已读标记修复

2026-10-03，发布版本统一为 1.0.2；以下专项检查与截图来自发布前内部构建 1.0.3。最终 1.0.2 安装包的发布验证见 [发布记录](release-1.0.2.md)。

## 原因与修改

阅读采样在宿主检查“文档已选中、正文可见、IDE 窗口在前台”之外，还检查了网页的 `document.hasFocus()`。首次从话题列表打开文档时，输入焦点可能仍在列表或其他工具窗口；网页返回空的可见楼层，无法累积正文时长、标记已读或隐藏小蓝点。切换回来重新获得浏览器输入焦点后才恢复。

已移除网页输入焦点要求，保留网页可见性与正文几何判定。选中文档、IDE 前台、正文显示、设置开关、账号版本和页面标识仍由 `DocViewerPanel` 检查；连续采样、后台暂停、快速滚动不计入和补传规则继续生效。小蓝点由本地有效阅读样本即时更新，不等待上传或切换页面。

## 回归验证

- 在实际 IntelliJ IDEA Ultimate 2026.2.3 / IU-262.10968.63 中，通过生产 `LinuxDoTopicFileEditor` 首次创建并加载一个全新模拟话题；在异步浏览器就绪前执行首次选中通知，没有切换标签页或手动发送阅读样本。
- 将输入焦点保留在“IDE 工具窗口焦点”按钮，确认网页可见且 `document.hasFocus()=false`，最初两个楼层均有未读小蓝点。
- 原 1.0.2 包在相同条件下持续采样 15 秒仍未标记，回归测试超时；1.0.3 的两个可见楼层自动标记已读、小蓝点消失，输入焦点仍留在工具窗口。
- 切走文档后等待两个采样周期，确认没有新增阅读时长。其余正文、Boost 和同步回归继续执行。
- 全量桌面测试 339 项通过；实际 IDEA 正文回归 58 项通过，包含新增的 4 项首次打开检查；安装包结构验证通过；Plugin Verifier 1.410 对目标 IDE 的结论为 **Compatible**，见[原始结论](reference/first-open-read-plugin-verifier.txt)。
- 在全新源码目录再次构建并执行全部桌面测试，安装包 SHA-256 与工作区构建一致。机器可读记录见[交付校验](reference/first-open-read-summary.json)。

实际 IDEA 记录见 [回归结果](reference/first-open-read-ide.txt)，截图见 [首次打开即标记已读](images/reader-first-open-read.png)。所有话题与计时请求由隔离内存传输处理，没有向真实论坛写入。

安装包：`build/distributions/linuxdo-jetbrains-plugin-1.0.2.zip`。源码包：`build/delivery/linuxdo-jetbrains-plugin-1.0.2-source.zip`。从 IDEA「设置 → 插件 → 齿轮 → 从磁盘安装插件」安装 1.0.2，并按提示重启。正常阅读需要开启自动阅读同步设置，当前文档留在前台并连续可见约两个采样周期。
