# 跨平台适配与验证

## 支持范围

目标平台为 Windows、macOS、Linux，使用同一 ZIP，架构跟随宿主 IDE/JBR 的 x64 或 ARM64 原生库。安装范围限制在 JetBrains **2026.2 / 262 至 262.***。插件调用隔离 remote JCEF 的私有接口，后续 IDE 分支需要重新验证后再扩大范围。

## 原生验收清单

每个目标系统/架构使用最终 ZIP，记录 OS、IDE build、JBR、JCEF 版本与校验和、显示缩放比例和日志路径：

1. 从磁盘安装、重启，打开列表与话题，检查类加载和浏览器渲染。
2. 真实账号登录、退出、切换账号、过期 Cookie、人机验证恢复原话题与楼层。
3. 中文输入法编辑发帖/回复、图片粘贴与上传、复制代码、外链与楼层跳转。
4. 长帖滚动、双向加载、Retina/混合 DPI；前后台阅读时间合并上报，关闭同步后不再发送。
5. 点赞失败回滚，发帖超时保留草稿且不自动重复提交。
6. 多次开关话题、项目和设置；老板键隐藏/恢复；检查监听器、任务、浏览器资源释放。
7. 卸载插件，按[隐私说明](privacy.md)清理本地数据，确认其他 IDE 浏览器未受影响。

执行入口及报告位置见[回归工具](../tools/README.md)。
