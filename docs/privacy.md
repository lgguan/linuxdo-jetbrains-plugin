# 隐私与本地数据

本插件由 lgguan 个人开发，是使用 https://linux.do 论坛接口的非官方客户端，与 Linux Do 官方和 JetBrains 无隶属关系。插件没有独立的分析或遥测服务。登录、浏览、点赞、发帖、图片上传、通知和阅读同步会向 Linux Do 发出对应请求；正文图片也可能从帖子引用的外部 CDN 加载。外部链接由系统浏览器打开。默认启用 LinuxDo DoH（`https://ldh.ddd.oaifree.com/query-dns`）；该服务会收到域名查询。用户可在设置中改为自定义解析服务或禁用 DoH，使用系统 DNS。DoH 服务自身的域名通过系统 DNS 引导解析。

帖子收藏、提醒、回应、编辑、举报、软删除、恢复、投票与采纳答案由用户点击提交到 Linux Do。编辑原因和修改正文按论坛规则保存；编辑窗口不使用新话题或回复草稿，也不新增本机正文文件。公式、Mermaid 和代码高亮引擎随插件打包，运行时不从 CDN 下载。点击“加载播放器”后，视频页面连接 `player.bilibili.com` 或 `www.youtube-nocookie.com`；播放器可能加载其自身资源，但不能访问插件的 IDE 网桥。保存图片写入用户在文件对话框中选择的位置。

## 保存位置与清理

下文的 IDE Config、System、Log 目录可在 IDE 的 Help → Diagnostic Tools → Special Files and Folders 中查看；具体绝对路径随产品、版本和操作系统变化。

| 数据 | 保存位置 | 清理方式 |
| --- | --- | --- |
| `_t`、`_forum_session`、`cf_clearance` | JetBrains PasswordSafe，服务名 `LinuxDoPlugin` 下的插件凭据；具体后端由 IDE/系统设置决定 | 插件设置或登录窗口点击退出登录；会清除插件保存的凭据及当前私有浏览器 Cookie |
| 浏览器 Cookie、页面缓存、本地存储 | IDE System 下 `linuxdo-private-jcef/<配置标识>/` | 退出登录会清除 Cookie；完全清除浏览器缓存及网站存储需先关闭 IDE，再删除该插件目录 |
| 图片下载、预览与复制原图文件 | IDE System 下 `linuxdo-plugin-images/` | 写入时按 7 天期限和 256 MB 总容量清理；关闭 IDE 后可删除整个目录。剪贴板可能继续引用其中的文件 |
| 阅读位置、实际已读楼层 | IDE Config 的 `options/LinuxDoReadTracking.xml`，按账号 ID 与游客分开保存 | 关闭 IDE 后删除此文件；退出登录保留各账号记录，便于下次恢复 |
| 待同步阅读批次 | 同一 `options/LinuxDoReadTracking.xml`，按论坛地址、账号 ID 和话题保存批次 ID、楼层及话题停留时长、重试与暂停状态；不包含正文或凭据 | 关闭自动同步暂停采集与上传；退出登录暂停对应账号补传，恢复登录继续；关闭 IDE 后删除该文件可清理 |
| 普通回复草稿正文及回复对象 | Linux Do 论坛，按账号和话题保存，键为 `topic_<话题ID>`；插件不新增本机正文文件 | 回复窗口选择“舍弃草稿”，或在论坛网页删除；其他客户端已修改的版本会保留 |
| 普通新话题草稿标题、正文、版块和标签 | Linux Do 论坛，按账号使用原生单份 `new_topic` 草稿，打开新建入口时自动恢复；不新增本机标题或正文文件 | 新话题窗口选择“舍弃草稿”，或在论坛网页删除；其他客户端已修改的版本会保留 |
| 个人显示和网络设置 | IDE Config 的 `options/LinuxDoSettings.xml` | 在设置中调整；关闭 IDE 后删除文件可恢复默认设置 |
| 历史分类缓存 | IDE Config 的 `options/LinuxDoCategories.xml` | 旧缓存不再进入当前发布表单；可在关闭 IDE 后删除 |
| 常规日志 | IDE Log 的 `linuxdo.log`、轮转文件及 IDE `idea.log`；独立 JCEF 另有 `linuxdo-private-jcef.log`、`linuxdo-private-chromium.log` | 关闭 IDE 后删除插件日志（IDE 日志目录不可用时，插件日志回退到用户主目录 `.linuxdo/logs/`）；常规插件日志只记录操作、状态、耗时及必要标识，不记录正文和标题 |
| 可选网络诊断 | IDE Log 的 `linuxdo-netlog-<标识>.json` 与 `.consumed` 标记 | 默认关闭，在设置中手动启用；重启后单次采集，支持的 JCEF 运行时最多 5 分钟、50 MB；复现后关闭 IDE并删除对应文件 |

网络诊断可能包含域名、地址、请求 URL 和网络元数据。分享前应自行检查和脱敏；不要公开 Cookie、账号内容或完整诊断文件。插件普通日志会对凭据与 URL 脱敏，Chromium 原始诊断不受这一过滤器处理。

“自动向社区同步阅读进度与停留时长”可在设置中关闭。开启时，每秒采样当前选中文档的可见正文，IDE 后台、休眠和长时间卡顿不计时；3 分钟无阅读滚动暂停，每楼每次阅读最多 6 分钟。新读楼层及时归并，其他时长每 60 秒归并，切换、关闭或后台时收集余量。上传按账号串行，每批话题及各楼层时长不超过 60 秒；失败数据留在本地队列，恢复网络及对应账号验证后补传。成功批次出队；接口没有时长幂等键，响应丢失后重试可能造成服务器时长重复累计。阅读位置在本地仍可保存。

普通回复窗口先读取论坛草稿，输入停止 2 秒后将正文和回复对象同步到 Linux Do。每个账号、话题共用一个活动编辑器；网页与插件共享同一草稿。关闭窗口可保存并关闭、舍弃或继续编辑。保存失败时，正文仍在窗口中，不显示保存成功；序列冲突时暂停同步，由用户对照完整正文和回复对象选择版本。不支持的帖子编辑、私信、共享草稿或特殊表单草稿不会被插件改写。

编辑内容保留在窗口内存中，插件不新增本机正文持久化。重启只能恢复已成功同步到论坛的回复或新话题草稿；未同步内容会丢失。发送失败保留正文，发送成功后仅清理本次拥有的草稿；其他客户端的新版本会保留。微回复仍只在窗口中暂存。插件卸载不保证 IDE 自动删除上述本地文件，也不会删除论坛草稿；需要彻底移除时，先退出登录，关闭 IDE，再清理列出的插件专属文件和目录。

普通新话题草稿按账号使用论坛原生 `new_topic` 键保存，新建入口直接打开编辑器并自动恢复已有草稿；每个账号只打开一个活动的新话题编辑器。冲突对照完整标题、正文、版块和标签选择版本。空白表单不会自动保存。

预览默认收起；打开后才渲染并随输入更新。关闭预览会丢弃未完成的渲染回调。本地预览不调用论坛渲染接口，图片可能按其原地址加载。手动选择“论坛引擎预览”会在插件私有浏览器中读取论坛应用并调用前端渲染引擎；临时浏览器禁止写入请求，完成或超时后销毁。该操作不发送帖子、不保存草稿。浏览器页面和资源缓存仍遵循上表所列清理方式。
